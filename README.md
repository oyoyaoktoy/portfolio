# Oyoya's Portfolio

Personal portfolio of Oyoya Oktoy, software engineer.

## Run locally

```bash
python3 -m http.server 5500
```

Then open http://localhost:5500

## Structure

- `index.html` page content
- `css/styles.css` styles, light and dark mode
- `js/script.js` theme toggle, resume viewer, copy email
- `images/` photo and project logos
- `images/screens/` project screen designs
- `resume/` CV as PDF and image
